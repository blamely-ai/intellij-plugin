Blamely

AI & Human attribution for IntelliJ and JetBrains IDEs. Track which lines are from AI (Copilot, Cursor, etc.) and which are human-written — then commit with Git notes.

Open standard & ecosystem. Blamely uses the same idea as Blamely: track AI code through the SDLC with Git Notes (refs/notes/blamely), so attribution survives rebases, merges, and cherry-picks. Blamely’s docs and CLI complement this plugin for a full workflow. blamely.ai

Screenshots

Changes tab (per-file AI / Human breakdown), History tab (commits, authors, AI models), and status bar (click to open details).

How it works

  • Line-level blame — Each line is attributed to AI or human (e.g. 50% rule: line is AI if ≥50% of its characters came from AI).
  • Persistence under .git/blamely — Session and per-file blame snapshots; no workspace clutter.
  • Git notes — A report.yml summary is attached to each commit via git notes --ref=blamely.
  • Status bar — Live AI / Human character and line counts; click to open the Blamely tool window.
  • Supported in-IDE AI — Detects GitHub Copilot (completions, chat panel, inline), Cursor, Codeium, and similar agents when you accept their suggestions.

Install

1. Build the plugin 
# From the plugin project root (JDK 17)
./gradlew buildPlugin

Output: build/distributions/Blamely-0.2.0.zip

2. Install in IntelliJ

Settings → Plugins → ⚙️ → Install Plugin from Disk → select the .zip file.

3. Restart the IDE

After restart, the Blamely status bar widget and tool window are available.

How to use

  • Code as usual — Type (human) or accept AI suggestions (Copilot, Cursor, etc.). The plugin attributes changes and updates the status bar (e.g. 🤖 AI: 20 ⓒ 2 ≡ 40% | 👤 Human: 30 ⓒ 3 ≡ 60%).
  • Tool window — Open View → Tool Windows → Blamely (or click the status bar) to see per-file AI / Human character and line breakdown.
  • Commit — On commit, the plugin writes a blame snapshot and report into a Git note for that commit. The status bar resets for the next session.
  • Push notes to remote — Automatic. A git pre-push hook pushes refs/notes/blamely whenever you push (IDE or CLI). If you already have a pre-push hook, Blamely only appends its block (your hook is never overwritten).
  • Tools menu — Tools → Blamely: Generate Report Now, Show Blame for Current File, Install Git Commit Hook, Show Report for Latest Commit (Git Note), Push AI Notes to Remote.

Report format

Each commit can have a Git note (ref refs/notes/blamely) containing YAML metadata and a blame_snapshot JSON (per-file line blame: author_type, provider, model, prompt, interaction_type). Same layout as the Blamely VS Code extension so you can use one repo in both IDEs with shared attribution.
