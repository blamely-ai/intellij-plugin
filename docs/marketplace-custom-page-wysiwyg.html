AI / Human attribution inside IntelliJ IDEA

Blamely analyzes your git history and attributes lines to AI-assisted edits versus human-authored code. Results show up in a native tool window, gutter hints, and optional git hooks - no cloud account required for core tracking.

You wrote the prompt. Who wrote the code?

Why teams use Blamely

  • Line-level AI vs human breakdown per file and commit
  • See which AI models contributed and rough share of AI-written lines
  • Branch-aware sessions, reports, and blame snapshots under .git/blamely
  • Optional pre-commit / pre-push helpers and git notes (refs/notes/blamely) for portable summaries
  • Same on-disk format as the Blamely VS Code extension - share one repo across IDEs

Supported AI providers (examples)

GitHub Copilot (Chat, Inline, Completion) | Cursor | Codeium | Tabnine | Supermaven | CodeGPT | Amazon CodeWhisperer | JetBrains AI

Requirements

  • Git Integration (bundled Git4Idea plugin) must be enabled.
  • Optional: node on PATH if you use the bundled hook runner features that rely on it.
